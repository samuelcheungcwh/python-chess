### Project Title

This project examines what makes decision-making in chess difficult, 
so that we can further understand human's decision in a complex environment

### Description

We first start by inputting 1000 games from a top-rated player in Lichess. 
Then we extract different game, time, and position characteristics for those 1000 games.
Our purpose is to create a reduced-form model regressing centipawn loss(CL) on various variables.
